## braces 无上游修复版本的漏洞

额外依赖审计发现 [GHSA-vfj7-8cjw-p6xm / CVE-2026-93687](https://github.com/advisories/GHSA-vfj7-8cjw-p6xm)。截至核对时，最新的 braces 3.0.3 没有发布修复版本。

通过 `pnpm.patchedDependencies` 应用 `patches/braces@3.0.3.patch`，限制 parser 的嵌套栈和 compile、expand、stringify 的递归深度。超过限制抛出受控 SyntaxError，防止耗尽调用栈。回归测试使用 Tailwind 实际解析到的已安装依赖，覆盖长度限制内的深层输入、未闭合输入、直接传入的深层 AST，以及正常构建 glob。

标准 `pnpm audit` 仍按版本报告这 1 条 high 告警。没有配置 ignoreGhsas，也没有 dismiss GitHub 告警。`pnpm audit:security` 只允许这个编号、这个版本和四处深度补丁均存在的本地缓解；其他告警及审计失败均阻断 CI。CI 在审计前运行补丁回归测试。上游发布安全版本后应改用正式版本并删除本地补丁和这条门禁例外。
